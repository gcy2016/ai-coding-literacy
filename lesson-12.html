第 12 节

API：程序之间怎么对话

1 一句话结论
API 就是程序之间的服务窗口：按格式递单，按格式拿结果。

2先打个比方：服务窗口

去政务大厅办证：你不用认识里面的人，只要按窗口贴的格式填好单子、带齐证件递进去，里面办好再把结果从窗口递出来。程序之间办事也是这样：不进对方的门，只在窗口按约定交单、拿结果。

图：不进门，只在窗口交单、拿结果

3正文

API，是程序之间的窗口。API（Application Programming Interface，应用程序编程接口）是事先约好的对话格式：一边按格式递单子，一边按格式回结果。人办事用鼠标点界面，程序办事靠它喊话。

人用界面程序用 API
谁在操作人，眼睛看、手点程序，按格式发请求
拿到什么排版好的页面结构化数据，接着加工

递的单子上写三样。地址：找哪个窗口办事；参数：要办的事的细节，比如一串经纬度；密钥：证明你有资格办的证件。三样齐了，对方才受理。

地址找哪个窗口
参数办事的细节
密钥资格证件

回的单子，是结构化数据。返回的多半是 JSON（第 05 节学过的那种格式）：字段固定、机器好读。它不是给人看的页面，是给程序接着加工的原料——相册拿到地址文字，再显示到页面上给你看。

{ "address": "重庆市渝北区……", "district": "渝北区" }

用别人的窗口，叫第三方服务。地图、存储、支付这些能力，多数程序不自己建，直接调别人家的 API：省事，但要守人家的规矩、按人家的量计费；人家的窗口关了，你这块功能也跟着停。

省事不用自己造轮子
守规矩按人家的格式来
有依赖人家停你也停

4对应到你的项目：相册问腾讯地图要地址

相册自己没有「坐标变地址」的本事。你在相册里点定位，拿到的是经纬度数字；想显示中文地址，它就去调腾讯位置服务的 API：请求发到 https://apis.map.qq.com/ws/geocoder/v1/，带上 location（经纬度）和 key（密钥），对方回一段带地址的 JSON，它再显示到页面上。第 8 块有这次请求的逐行拆解。

它的密钥防盗用，靠域名白名单。这个 key 是写在网页里的，谁打开页面都能看见——但腾讯那边设了规矩：只认从 gcy2016.github.io 发出的请求。别人把 key 抄走，换个网站用，腾讯直接不受理。代码注释里写的就是这个安排。

相册和 COS 之间，也是 API 对话。网页读一个文件，用的是 getObject（读取文件）；存一个文件，用的是 putObject（写入文件）。你每次打开相册、保存相册，背后都是在跟 COS 的窗口递单、拿单。

5和 AI 协作时怎么用

可以这样说「这个功能是调谁的 API？请求里带什么、返回什么格式？先讲清再写。」
可以这样说「密钥准备怎么保管？有没有配域名白名单或权限限制？」
可以这样说「这家服务要是停了或涨价了，这块功能有没有退路？」
别这样说「你把定位功能加上。」——没说用哪家服务、地址显示成什么样，AI 只能乱猜乱接。

7小测（选完立刻看对错）

1. API 这套对话方式，是给谁用的？
解析：API 是程序之间的窗口：按格式发请求，按格式拿数据，不需要人参与。
2. 一次 API 请求里，通常不会带哪一样？
解析：请求带地址、参数、密钥；返回的是数据，排版是拿到数据之后前端自己的事。
3. API 密钥最像下面哪样东西？
解析：密钥证明「你是谁、有没有资格办」；正因为是证件，被人抄走就能冒名使用。
4.（情景）AI 说：「地图的 key 我直接写在网页里了，反正配了域名白名单。」你该怎么判断？
解析：公开网页里的 key 靠域名白名单兜底，是相册正在用的做法；前提是白名单确实生效，值得当场确认一句。
5. 相册和 COS 对话时，getObject 是什么意思？
解析：get 是「取」，getObject 就是从 COS 读一个文件；写文件用的是 putObject。
