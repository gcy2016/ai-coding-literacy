第 05 节

数据：变量、类型、列表、字典、JSON

1 一句话结论
数据先装进带标签的盒子，程序才找得到、用得对。

2先打个比方：仓库里的盒子

程序打交道的东西全是数据：车速、温度、一条报文、一张照片的信息。数据不会摊在地上，都装在「盒子」里：单个盒子贴上标签，叫变量；一排盒子排好队，叫列表；按名字查的格子柜，像通讯录，叫字典。这一节就认识这几种装法。

图：变量是盒子，列表是一排盒子，字典是通讯录

3正文

变量：贴标签的盒子。写 speed = 88，就是造一个叫 speed 的盒子、把 88 放进去。后面再说 speed，指的就是盒子里现在的值；值随时能换，换成 90，盒子还是那个盒子。

名字标签，找它靠这个
值盒子里装的东西
可换随时能重新赋值

类型：盒子里的东西分种类。类型（type）常见的有整数、小数、文字（字符串，string）、真假（布尔，boolean）。类型用错，轻则算错、重则报错——就像拿温度计去称体重，工具不对，读数没意义。

类型例子像什么
整数 / 小数88、36.5计数、仪表读数
字符串"重庆"一段文字
布尔真 / 假开关，只有两档

列表和字典：成批装数据。一堆同类的东西排成一排是列表（list），按序号取，像排队叫号；一组「名字 → 值」的配对是字典（dictionary），按名字直接查，像通讯录按人名查电话。

名字（键）值
"city""重庆"
"photos"36

JSON：把字典和列表写成文本。JSON（JavaScript Object Notation，一种到处都在用的数据写法）长相就是花括号配冒号。它既能存进文件，也能在程序之间传递，人和机器都读得懂，所以到处都是它。

4对应到你的项目：标记帧和相册数据

CANLink 的标记帧。你在 CANLink 里点「标记」时，它会往记录里插一帧特殊报文：ID 是 1FFFFFF0；8 个字节里，第 1–2 字节是标记序号，第 3 字节固定放 165（十六进制 0xA5）当暗号，第 5–8 字节是打下标记的时刻。这一帧写成 JSON 大致长这样：{"id": "1FFFFFF0", "data": [1, 0, 165, 0, ...]}——一个字典，键是 id 和 data，data 的值是一个列表。

相册的 album.json。相册里一条区域记录也是一个字典，包含区域编号、点亮日期、照片等信息；全部区域的记录汇在一起，整体存在一个叫 album.json 的文件里。文件名后缀 .json 的意思就是：这个文件里装的是 JSON 格式的数据，相册每次打开，先把这个文件读进来变成字典和列表再干活。

5和 AI 协作时怎么用

可以这样说「这个数据准备用什么结构存？是列表还是字典？先给我看一条真实样例。」
可以这样说「这个字段是什么类型？会不会出现空值，或者数字和文字混着来？」
别这样说「数据随便存一下，能跑就行。」——结构没定好，后面解析、统计、改版全跟着返工。

7小测（选完立刻看对错）

1. 代码里先写 count = 0，后来又写 count = 5。现在 count 里装的是几？
解析：变量就是盒子，值随时能换，后放的盖掉先放的，所以现在是 5。
2. 下面哪种数据最适合用字典来装？
解析：有名字、分项查的用字典；成排的同类数据用列表。
3. JSON 里写 {"city": "重庆", "photos": 36}，它表示什么？
解析：花括号是字典，冒号左边是名字（键），右边是值；文字带引号，数字不带。
4.（情景）AI 说：「接口返回的 JSON 里，这个字段有时是数字、有时是字符串，我先兼容处理了。」你最该留意什么？
解析：同一个字段类型忽数忽字，迟早在别的地方爆雷；兼容只是临时兜底，源头统一才干净。
5. 相册的 album.json 如果格式损坏、打不开了，最可能的影响是？
解析：album.json 就是相册的数据本体，文件坏了记录就读不出来——重要数据文件一定要有备份。

8读代码：一条标记帧是怎么装的

下面这段 Python（一种编程语言，本模块统一用它举例）是教学示例：先用一个字典表示一条标记帧，再把多帧装进一个列表。点任意一行，看这一行在干什么。

marker = {
"id": "1FFFFFF0",
"data": [1, 0, 165, 0, 12, 34, 0, 0],
}
frames = []
frames.append(marker)
frames.append({"id": "0CFF1234", "data": [88, 10]})
print(len(frames))
print(frames[0]["data"][2])
点任意一行，这里会显示这一行的中文解释。
